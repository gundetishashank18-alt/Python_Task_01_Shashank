# Programming Task 02 - Decision Making & Logic Building

## Objective
This task strengthens understanding of variables, operators, user input, conditional statements, and logical thinking using Python.

## Programs List

### 1. Even or Odd Checker - `even_odd.py`
Takes a number as input and checks whether it is Even or Odd.
**Example:** Input: 15 → Output: 15 is an Odd Number

### 2. Largest of Three Numbers - `largest_number.py`
Takes three numbers as input and finds the largest number.
**Example:** Input: 10, 25, 18 → Output: Largest Number = 25

### 3. Student Grade Calculator - `grade_calculator.py`
Accepts marks and displays grade based on criteria:
- 90-100: A
- 80-89: B
- 70-79: C
- 60-69: D
- Below 60: F

### 4. Simple Login Validation - `login_validation.py`
Stores predefined username: `admin` and password: `password123`. Validates user credentials.
**Example:** Correct credentials → Output: Login Successful

### 5. Password Strength Checker - `password_checker.py`
Checks password strength based on:
- Length >= 8 characters
- Contains at least one number
- Contains at least one uppercase letter
**Result:** Strong / Moderate / Weak Password
