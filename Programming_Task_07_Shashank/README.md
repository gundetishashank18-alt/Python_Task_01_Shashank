Python Programming - Task 07

Employee Management System

📌 Project Description

The Employee Management System is a menu-driven Python application developed using Object-Oriented Programming (OOP) concepts. This project helps manage employee records by allowing users to add, view, search, update, delete, and export employee information. It also provides salary statistics such as highest salary, lowest salary, average salary, and total number of employees.

This project is developed as part of Python Programming Internship - Task 07.

---

🎯 Objective

The objective of this project is to learn and implement Python Object-Oriented Programming concepts by building a real-world Employee Management System.

📋 Employee Details

Each employee record contains:

- Employee ID
- Employee Name
- Department
- Designation
- Salary

---

📖 Modules Included

1. Add Employee

Creates a new employee record and stores it in the employee list.

2. View Employees

Displays all employee records in a formatted table.

3. Search Employee

Searches employee details using Employee ID or Employee Name.

4. Update Employee

Updates Department, Designation, and Salary of an existing employee.

5. Delete Employee

Deletes an employee record using Employee ID.

6. Salary Statistics

Displays:

- Highest Salary
- Lowest Salary
- Average Salary
- Total Employees

7. Export Data

Exports all employee records to "employees.csv" and reads the file back.

▶️ How to Run

1. Open the project folder in Visual Studio Code.
2. Open the integrated terminal.
3. Run the following command:

python employee_management.py

4. Select options from the menu to perform operations.
