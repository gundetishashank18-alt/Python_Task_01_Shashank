Student Cyber Security Management System

Project Objective:

The objective of this project is to combine all concepts learned during the internship, including:

- Variables
- Input and Output
- Conditional Statements
- Loops
- Functions
- Lists
- File Handling
- Problem Solving
- Basic Cyber Security Concepts

This project demonstrates a menu-driven Student Cyber Security Management System developed using Python.

---

Features

Student Management

- Add Student
- View Students
- Search Student by Name or ID
- Delete Student Record

Security Assessment

- MFA Status Check
- Password Length Verification
- System Update Status
- Antivirus Status
- Security Score Generation
- Security Rating Classification

Report Generation

- Total Students
- Average Security Score
- Students with Poor Security Ratings

File Handling

- Save Records
- Read Records
- Update Records
- Delete Records

Cyber Security Features

- Password Strength Checker
- Username Generator
- Blacklist IP Checker

---

Technologies Used

- Python 3
- Lists
- Functions
- File Handling
- Conditional Statements
- Loops

---

Program Flow

1. Display Main Menu
2. Select an Option
3. Perform Required Operation
4. Save Changes to File
5. Return to Main Menu
6. Exit Program
