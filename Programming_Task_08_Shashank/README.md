Smart File Organizer

Python Programming Internship - Task 08

Project Overview

The Smart File Organizer is a Python application that automatically organizes files into different folders based on their file extensions. It scans a selected directory, creates category folders, moves files into their respective folders, displays file statistics, detects duplicate file names, allows file searching, and generates a report.

---

Objective

The main objective of this project is to automate file management using Python while learning file handling, directory management, exception handling, and automation techniques.

---

Features

- Select any folder from the system
- Scan all files in the selected folder
- Display total number of files
- Organize files automatically by file extension
- Create folders automatically if they do not exist
- Display category-wise file statistics
- Search files by file name
- Search files by extension
- Detect duplicate file names
- Generate a report named file_report.txt
- Handle invalid paths and file errors gracefully

How to Run

1. Open the project folder in Visual Studio Code.
2. Open the integrated terminal.
3. Run the following command:

python smart_file_organizer.py

4. Enter the folder path when prompted.
5. The program will organize files automatically and generate the report.
