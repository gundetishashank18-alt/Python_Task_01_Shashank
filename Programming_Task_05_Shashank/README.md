Objective

The purpose of this task is to understand how data is stored, processed, searched, and analyzed using Arrays (C) and Lists (Python). These concepts are commonly used in software development, automation, and cybersecurity applications.

---

Programs Included

Python Files

1. marks_analyzer.py
   
   - Accepts marks of 5 students.
   - Displays highest marks, lowest marks, and average marks.

2. search.py
   
   - Stores employee names in a list.
   - Searches for a user-entered employee name.
   - Displays whether the record is found or not.

3. statistics.py
   
   - Accepts 10 numbers from the user.
   - Displays largest number, smallest number, sum, average, even count, and odd count.

4. log.py
   
   - Analyzes login attempt records.
   - Displays total attempts, successful logins, and failed logins.
   - Explains the importance of monitoring failed logins.

5. IP_checker.py
   
   - Stores blacklisted IP addresses.
   - Checks whether a given IP address exists in the blacklist.
